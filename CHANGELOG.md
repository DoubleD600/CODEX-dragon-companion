# Changelog

## 1.0.0

- Reorganized into installable src package, configuration, data providers, desktop adapter and renderer.
- Added portable JSON task input and configurable desktop integration.
- Replaced thresholded transparency with Qt alpha compositing; rounded vector surfaces, smoother Chinese fonts.
- Preserved hover controls, click reactions, drag/resize, task links, tray menus and desktop startup watcher.
- Added single instance restore, reproducible build scripts, tests and release workflow.
